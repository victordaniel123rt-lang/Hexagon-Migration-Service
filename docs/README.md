# Documentación del proyecto

En esta carpeta se almacenarán recursos adicionales del proyecto, como diagramas, documentación de la arquitectura, ejemplos de uso, y cualquier material útil para desarrolladores y operaciones.

Sugerencias de archivos a añadir:
- `hexagonal-architecture.png` — Diagrama de la arquitectura hexagonal (imagen proporcionada).
- `api_endpoints.md` — Lista detallada de endpoints REST con ejemplos de request/response.
- `deployment.md` — Instrucciones de despliegue y configuración en entornos (Docker, Kubernetes, etc.).
- `design.md` — Notas de diseño y decisiones arquitectónicas.

Puedes agregar aquí la imagen del diagrama o cualquier otro recurso. Si quieres, la subo yo en la ruta `docs/hexagonal-architecture.png` y actualizo el `README.md` para referenciarla.
